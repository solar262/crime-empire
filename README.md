# Crime Empire

A browser-based crime empire idle strategy prototype.

## Play loop

- Collect cash
- Upgrade front businesses
- Recruit crew members
- Fight rivals
- Take over districts
- Save progress in the browser

## Files

- `index.html` — game screen
- `style.css` — mobile-friendly styling
- `game.js` — idle strategy game logic

## Hosting with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch: `main`.
6. Choose folder: `/root`.
7. Click **Save**.

The live game should appear at:

```text
https://solar262.github.io/crime-empire/
```

## Prototype note

This is a fictional, stylized idle strategy game prototype. It avoids realistic criminal instructions and focuses on upgrade loops, territory progression, and casual gameplay.
